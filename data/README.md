# Computed simulation evidence

These are generated numerical benchmarks, not measured flight data. NPZ arrays preserve training weights, trajectories, design points and field/finite-element results; JSON reports preserve metric definitions and failure cases. All 320 paired uncertainty cases are in `lhs_cases/`. Verified reference metadata are in `references/`. Historical quality audits record prepublication assembly; the root Zenodo publication receipt confirms subsequent public release. Generated data are CC BY 4.0.
